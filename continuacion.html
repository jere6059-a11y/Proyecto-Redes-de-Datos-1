Unidad 6

Instalación y Administración de Redes Pequeñas

Debemos tener en cuenta la estructura y ubicación de los equipos dentro de un ambiente laboral para realizar un diseño óptimo.

Red Cableada vs. Inalámbrica

  • Red Cableada: Puede superar fácilmente los 100 Mbps y llegar hasta 1 Gbps de transmisión estable.
  • Red Wi-Fi: Presenta una velocidad máxima de transmisión cercana a los 108 Mbps y depende del entorno.

Red Tipo "Estrella"

Teniendo en cuenta que vamos a conectar no más de 8 equipos a la red, la mejor opción topológica es armar una red de tipo estrella con un concentrador central.

Pasos para Instalar la Red Pequeña

  • Instalación Eléctrica: Es muy importante que el espacio donde se monte la red tenga una instalación eléctrica en óptimas condiciones.
  • Cálculo de Distancias: Una vez definido por dónde tender los cables de red, debemos calcular los metros necesarios.
  • Bosquejo y Canalización: Realizar un bosquejo del recorrido que seguirán los cables y pasarlos utilizando un cablecanal.
⚠️ Nota Importante: El cable de red no puede doblarse a más de 45°, ya que podría generarse un cortocircuito o la rotura interna de los hilos de cobre.
  • Conexionado y Rosetas: Pasar el cable por el cablecanal y, con la ayuda de una pinza crimpeadora (o de impacto), armar las fichas terminales y las rosetas con conectores RJ-45 hembra en cada puesto de trabajo.
  • Montaje y Verificación: Amurar el concentrador a la pared y conectar cada roseta a él. Con las fichas armadas, se procede a verificar que no existan cables mal armados ni cortados mediante un LAN Tester (probador de red).
Unidad 7

Parámetros de Configuración y Elementos de Red

Con la red físicamente armada, se conectan las computadoras instalando previamente las interfaces de red en caso de no contar con una integrada.

Parámetros de Configuración (Software)

Nombre de Equipo

Para una red pequeña los parámetros son sencillos: asignar un nombre único a cada equipo junto con una descripción para reconocer cada PC en la red.

Grupo de Trabajo

Establecer el nombre del grupo de trabajo, el cual debe ser exactamente el mismo para todas las computadoras que conforman la red local.

Elementos de Red y Dispositivos de Conectividad

Insumos y Componentes

  • Cable UTP Cat. 5
  • Fichas RJ-45 (macho / hembra)
  • Capuchones de red
  • Módem / Switch / Router

Equipos de Conectividad

  • Módem USB ADSL
  • Módem / Router ADSL
  • Router Wi-Fi
  • Interfaz de red WLAN (Inalámbrica)
Unidad 8

Cable UTP y Normas de Ponchado (T568A / T568B)

Un Cable UTP (Unshielded Twisted Pair) es un cordón resguardado por un recubrimiento plástico que permite la conducción eléctrica o distintos tipos de señales. Contiene pares trenzados sin blindaje y es clave en las telecomunicaciones.

Ventajas del Cableado Estructurado

  • Minimiza tiempo y costos, aumentando el rendimiento de los equipos.
  • Optimiza y permite compartir recursos ya que es administrable por el usuario.
  • Mejora y facilita el mantenimiento técnico de la red.

Unidad 9

Fundamentos de Redes de Datos y Arquitectura

Una Red de Datos es un conjunto de equipos informáticos y dispositivos conectados entre sí mediante medios físicos o inalámbricos, con el objetivo de compartir información y recursos.

Usabilidad de una Red

Permite enviar correos, imprimir desde cualquier PC, compartir archivos y acceder a Internet de manera fluida.

Ventajas Principales

Ahorro de recursos, comunicación rápida, trabajo colaborativo y acceso centralizado a la información.

Arquitectura de Red

Es el diseño y la organización de los componentes de una red. Define cómo se comunican los dispositivos. Las principales tecnologías históricas y actuales fueron:

ARCnet

Una de las primeras redes para oficinas. Usaba topología de BUS y era lenta para los estándares actuales.

Token Ring

Utilizaba un "testigo" o token que circulaba por la red. Solo el equipo con el token podía transmitir datos.

Ethernet

Es el estándar más utilizado hoy en día. Permite altas velocidades y utiliza el protocolo CSMA/CD para evitar colisiones de datos en el medio.

Protocolos de Red

Son las reglas que permiten que dos dispositivos se entiendan. Sin protocolos, la comunicación no sería posible. Ejemplos (todos siglas):

TCP / IP

Conjunto de protocolos base para la transmisión e interconexión en Internet.

HTTP & FTP

HTTP: Transferencia de páginas web.
FTP: Transferencia de archivos.

Unidad 10

Modelo OSI, Tipos de Red y Modelo Cliente/Servidor

El Modelo OSI

Es un modelo teórico de 7 capas que explica cómo viajan los datos desde un dispositivo a otro:

Nº Capa Nombre de Capa Función Principal
7AplicaciónInterfaz con las aplicaciones del usuario final.
6PresentaciónFormato, cifrado y traducción de los datos.
5SesiónApertura, mantenimiento y cierre de sesiones.
4TransporteTransferencia de datos confiable entre extremos.
3RedDireccionamiento lógico y enrutamiento (ej. IP).
2Enlace de DatosDireccionamiento físico (MAC) y control de errores.
1FísicaTransmisión de bits a través de medios físicos.
💡 Utilidad del Modelo OSI: Sirve para entender y resolver problemas de red ordenadamente capa por capa.

Tipos de Red según su Alcance

PAN

Conecta dispositivos cercanos a una persona. Ejemplo: Auricular Bluetooth conectado con el celular.

LAN

Cubre un espacio pequeño como una aula, casa u oficina.

MAN

Conecta varias LAN dentro de una misma ciudad.

WAN

Cubre grandes distancias (países, continentes). Internet es la red WAN más grande.

Modelo Cliente / Servidor

Es un modelo donde los clientes solicitan servicios y los servidores los proveen.

Ejemplo práctico: Cuando usted abre una página web en el navegador, su PC actúa como el cliente y el servidor web le envía la página solicitada.

Unidad 11

Topologías, Medios de Transmisión y Digitalización

Topologías de Red

Es la forma física o lógica en que se conectan los dispositivos:

Bus

Todos los equipos están conectados a un mismo cable principal.

Estrella

Todos los equipos están conectados a un dispositivo central como un Switch.

Anillo

Los equipos forman un círculo cerrado de conexión.

Medios de Transmisión

Medios Guiados

Usan un cable físico para la señal. Ejemplos: Par trenzado, cable coaxial y fibra óptica.

Medios No Guiados

Transmiten sin cables por el aire. Ejemplos: Wi-Fi, ondas de radio e infrarrojo.

Digitalización de Señales

Es el proceso de convertir información analógica, como la voz, en señales digitales de 0 y 1 para que la computadora pueda procesarla y transmitirla.
